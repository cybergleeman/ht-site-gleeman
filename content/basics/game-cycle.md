# 赛季与每周节奏

> 状态：⚪ 待核实 ｜ 最后更新：2026-10-18 ｜ 条目：BAS-010 ~ BAS-011

所有「什么时候结算」的问题都归这里。时点错一天，结论就全错，所以这部分需要你给准确信息。

## 一周循环

### `BAS-010` 每周固定节奏

- **状态**：⚪ 待核实 · C
- **主张**：联赛在周末、杯赛与友谊赛在周中；训练、经济、状态、赞助等在每周固定时点结算。
- **待核对**：
  - 联赛 / 杯赛 / 友谊赛分别是周几。
  - 训练每周结算一次还是多次；结算在周几几点（服务器时区）。
  - 状态、体能、经济、赞助、球迷情绪的结算频率是否一致。

## 赛季结构

### `BAS-011` 赛季长度与升降级

- **状态**：⚪ 待核实 · C
- **主张**：一个赛季约 3 个月，赛季末按名次升降级，存在直接升级与附加赛两种路径。
- **待核对**：
  - 每个联赛组几支球队、几轮比赛。
  - 直升级名额、附加赛名额、降级名额各几个。
  - 共有几个联赛级别，最低级别是否不再降级。
