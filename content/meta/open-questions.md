# 未解问题 / 待验证假说

> 按「对决策影响大小」排序。解决一条，就把它挪进对应主题文件并标 ✅。

## 第一优先（直接影响排兵与训练）

1. **训练结算时点**：每周几结算、算几次、跨周是否溢出。
   - 影响：所有「什么时候练满」的判断。
   - 验证：对比周界前后的技能小数位。
2. **训练速度的年龄曲线**：断点在哪、30 岁后是否归零。
   - 影响：球员该练还是该卖。
   - 验证：同一训练类型下多年龄段对照。
3. **教练 / 助教 / 强度的加成系数**：是否线性、是否叠加。
   - 影响：钱花在教练还是助教。
4. **评级公式**：位置权重 + 状态 / 经验 / 体能乘数。
   - 影响：换阵、买人的性价比判断。
5. **门票最优价**：票价与上座的弹性曲线。
   - 影响：主场收入。

## 第二优先（影响战术与选人）

6. 战术的数值代价（扣哪块评级、扣多少）
7. 天气档位与特长加成表
8. 事件概率模型（进球 / 受伤 / 红牌）
9. 状态更新频率与替补是否受益
10. 体能对比赛评级的衰减曲线

## 第三优先（长期经营）

11. 球迷人数增长公式
12. 赞助档位与挂钩变量
13. 球员身价权重（技能 × 年龄 × 特长）
14. 青训抽人质量与球探关系
15. 升降级 / 附加赛的确切规则

## 存疑待查

- 是否存在「隐藏天赋」属性，以及能否观测。
- 「受伤倾向」是否可见。
- 评级是否每场随机浮动。
